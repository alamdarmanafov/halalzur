Qeyd: giriş e-poçtu/şifrəsi artıq server tərəfində (Vercel funksiyası, environment variable) yoxlanılır — bu faylda açıq görünmür. Amma aşağıdakı təsdiq/rədd əməliyyatları hələ də Supabase-in anon açarı ilə birbaşa göndərilir, real istifadəçi sessiyası (Supabase Auth) yoxdur — bu, panelin təsadüfi ziyarətçilərdən gizlədilməsidir, tam giriş nəzarəti deyil.
